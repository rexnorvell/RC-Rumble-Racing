# RC-Rumble-Racing

This is a Python implementation of a game called RC Rumble Racing. In the game, the player ventures on a solo campaign across four tracks. To unlock the next track, the user must beat the easy and medium CPU “ghosts” on the current track. The racing itself is a top-down view of the current track as the player controls the car with their keyboard.

# Play on the Web

To run the game in the browser, simply visit the GitHub Pages deployment at [this link](https://rexnorvell.github.io/RC-Rumble-Racing).

# Play Locally

To run the game on your local machine, use the following set of commands:

- `git clone https://github.com/rexnorvell/RC-Rumble-Racing` - download the code
- `python3 -m venv .venv` - create a Python virtual environment
- `source .venv/bin/activate` - activate the virtual environment
- `pip install -r requirements.txt` - install the required dependencies
- `cd RC-Rumble-Racing/src` - navigate to the directory containing the app's source code
- `python3 main.py` - run the app
